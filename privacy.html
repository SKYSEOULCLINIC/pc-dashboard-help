시행일: 2026년 11월 18일

1. 프로그램과 운영 주체

  • 프로그램은 지역사회 일차의료 혁신 시범사업에 참여하는 의료기관이 환자의 시범사업 신청·동의서와 자가 문진을 받고, 그 내용을 해당 의료기관의 PC에 보관하며, 건강보험심사평가원 시범사업자료제출시스템(aq.hira.or.kr) 입력을 돕기 위해 만들었습니다.
  • 프로그램 개발·배포: SKY서울가정의학과의원 (문의 drsuhclinic@gmail.com)
  • 프로그램으로 처리하는 환자 개인정보의 처리자는 프로그램을 사용하는 각 의료기관입니다. 개발자는 사용 기관의 환자 정보를 받거나 볼 수 없습니다.

2. 처리하는 정보

3. 이용 목적

  • 시범사업 신청서·동의서·자가 문진의 작성과 PDF·MD 문서 보관
  • 사용자가 직접 로그인한 심평원 시범사업자료제출시스템의 대상자 등록·포괄평가 계획수립 화면에 값을 입력하는 보조(최종 판단과 제출은 사용 기관이 함)
  • 연결 상태 확인과 오류 원인 분석

4. 제3자 제공과 외부 전송

  • 프로그램은 개발자나 다른 외부 서버로 정보를 보내지 않습니다. 분석·광고·추적 기능이 없습니다.
  • PC 프로그램과 태블릿은 사용 기관의 내부 네트워크에서만 통신하며, 같은 네트워크에서 등록(페어링)된 태블릿만 접속할 수 있습니다.
  • PC 프로그램과 브라우저 확장은 같은 PC 안(127.0.0.1)에서만 통신합니다.
  • 브라우저 확장은 사용자가 요청한 작업에 한해 사용자가 로그인해 둔 심평원 사이트 화면에 값을 입력합니다. 이 입력은 사용 기관이 심평원에 제출하는 업무의 일부입니다.

5. 보관과 파기

  • 환자 기록과 문서는 사용 기관 PC에 보관되며, 프로그램은 자동으로 지우지 않습니다. 시범사업 기준에 따른 보관 기간(최초 동의 완료 후 5년)과 파기는 사용 기관이 관리합니다.
  • 동작 로그는 90일이 지나면 프로그램이 자동으로 지웁니다.
  • 브라우저 확장은 환자 정보를 저장하지 않으며, 확장을 삭제하면 연결 정보도 함께 지워집니다.

6. 안전성 확보 조치

  • 운영자 로그인 후에만 기록에 접근하며, 비밀번호는 암호화 값(해시)으로만 저장합니다.
  • 태블릿 접속은 같은 내부 네트워크와 등록된 기기로 제한하고, 선택적으로 암호화 통신(HTTPS)을 씁니다.
  • 브라우저 확장과의 통신은 PC 내부 주소로 제한하고, 고정된 확장 식별자와 연결 토큰을 확인합니다.
  • 프로그램 화면의 목록에서는 주민등록번호를 가려서 보여 줍니다.

7. 브라우저 확장의 권한

http://127.0.0.1/*같은 PC의 PC 프로그램과 통신

브라우저 확장이 다루는 사용자 데이터는 위 단일 목적(심평원 시범사업 입력 보조)에만 쓰며, 판매하거나 다른 목적(광고, 신용 평가 등)으로 쓰거나 넘기지 않습니다.

8. 정보주체의 권리

환자는 자신의 정보에 대한 열람·정정·삭제·처리정지 등을 진료받은 의료기관에 요청할 수 있습니다. 의료기관은 관련 법령과 시범사업 기준에 따라 처리합니다.
